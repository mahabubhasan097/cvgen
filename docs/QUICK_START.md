# ⚡ Quick Start Guide - CVGen

## 🚀 Get Running in 2 Minutes

### Installation & Setup

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Open browser
# Visit http://localhost:3000
```

That's it! You're ready to create resumes! 🎉

---

## 📝 Basic Usage

### Edit Your Resume
1. **Click any text** to edit inline
2. Type your changes
3. Press **Enter** to save or **Escape** to cancel
4. Changes **auto-save** automatically

### Customize Appearance
1. Look at the **bottom toolbar** (Quick Customizer)
2. Click emoji buttons for layout: 📄 Compact, 📃 Normal, 📰 Spacious
3. Click color swatches to change theme
4. Use A-/A+ to adjust font size
5. Toggle icons ON/OFF

### Advanced Customization
1. Click **"More Options"** in bottom toolbar
2. OR click **"Customize"** button in left panel
3. Use **3 tabs** for different options:
   - **Quick**: Presets, themes, bullets, colors
   - **Advanced**: Font sizes, spacing, borders
   - **Sections**: Show/hide, reorder, rename sections

### Export Your Resume
1. Click **"Save as PDF"** button
2. Follow the instructions in the modal
3. Use browser print → Save as PDF
4. Your ATS-friendly resume is ready! 📥

## 🎯 Quick Customization Guide

### Change Layout
**Bottom Toolbar → Layout Buttons**
- 📄 Compact: Fit more content
- 📃 Normal: Balanced (default)
- 📰 Spacious: Airy, emphasize content

### Change Colors
**Bottom Toolbar → Theme Swatches**
- Black, Blue, Purple, Green, Gray
- Click to apply instantly

### Change Font
**Bottom Toolbar → Font Dropdown**
- Inter, Arial, Helvetica, Calibri, Georgia, Times New Roman, Verdana

### Adjust Text Size
**Bottom Toolbar → A- / A+**
- A- makes text smaller
- A+ makes text larger

### Change Header Style
**Bottom Toolbar → Header Buttons**
- ═ Underline (ATS-friendly)
- ▓ Background (bold)
- ▭ Border (structured)

### Toggle Icons
**Bottom Toolbar → Icons Button**
- ON: Show contact icons
- OFF: Hide contact icons

## 🎯 Tips for IT Professionals

### Content Best Practices
✅ Use action verbs (Led, Developed, Architected)  
✅ Include metrics (Improved by 40%)  
✅ List technologies used  
✅ Show business impact  

### Formatting Best Practices
✅ Keep to 1 page if possible  
✅ Use consistent date formats  
✅ Include job description keywords  
✅ Proofread thoroughly  

### ATS Optimization
✅ Use underline header style  
✅ Keep body font 12-14px  
✅ Use standard fonts (Arial, Calibri)  
✅ Disc or circle bullets  
✅ Classic Black or Professional Blue theme

## 🐛 Quick Troubleshooting

### Port Already in Use
```bash
npm run dev -- -p 3001
```

### Changes Not Saving
- Check browser console for errors
- Ensure localStorage is enabled
- Clear browser cache and refresh

### PDF Looks Wrong
- Use Chrome or Edge (recommended)
- Check print preview first
- Ensure fonts are loaded

### Build Errors
```bash
rm -rf node_modules .next
npm install
npm run build
```
